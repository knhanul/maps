GPX를 선택하면 읽기 결과가 여기에 표시됩니다.

새 코스와 GPX 수정본을 같은 지도에서 편집합니다. 원본 파일은 바뀌지 않습니다.

1 위치 맞추기기준점 없음

이미지와 바탕 지도의 같은 지점을 2곳 이상 짝지으면 크기·회전까지 자동으로 맞춥니다. 가운데 ✥를 끌면 이동, 모서리 ◢를 끌면 크기·회전입니다.

2 선 색 고르기
3 출발·도착

값이 클수록 선을 벗어난 지름길을 피합니다. 화살표 아이콘·글자로 선이 끊긴 곳은 짧게 건너뜁니다.

4 추출 · 보정

이미지 해상도 때문에 선이 실제 길과 수십 m 어긋날 수 있습니다. 보정은 추출한 선 위의 경유점만 길담 경로 서버로 보내 실제 길로 다시 잇습니다.

번호로 선택 · 범위 직접 입력

길 따라 다시 그리기는 현재 활동 유형 기준이며, 확인 후 양 끝점 2개만 길담 서버로 보냅니다(30km 이내). 대체 경로는 별도 구간으로 저장해 원본과의 틈을 임의 직선으로 잇지 않습니다.

수정·추가한 점에는 시각·고도·확장값이 없습니다. 원본 파일은 바뀌지 않습니다.

지도를 눌러 지점을 추가하고, 점을 끌어 옮기세요. 길 따라 자동 연결 지점 간격은 30km 이내로 찍으세요. 지점을 오른쪽 클릭하면 삭제합니다.

길 따라 모드에서는 찍은 경유점만 길담 서버로 보내 계산합니다. GPX 파일은 브라우저에서만 읽습니다. 지도에 없는 길·통제·위험구간은 반영되지 않을 수 있습니다.

⛰ 고도는 지형 고도 데이터(DEM)에서 읽어요. 30m 해상도라 실제와 조금 다를 수 있어요.
