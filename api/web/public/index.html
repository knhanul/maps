현재 새 코스 편집

GPX를 선택하면 읽기 결과가 여기에 표시됩니다.

새 코스와 GPX 수정본을 같은 지도에서 편집합니다. 원본 파일은 바뀌지 않습니다.

회색: 원본 · 빨강: 수정본 · 주황: 적용 전 경로. 작은 원을 직접 끌어 점을 이동할 수 있습니다. 원본 GPX의 모든 점과 끊긴 구간을 유지합니다.

고급 · 선택 구간 길 따라 / 범위 자르기

번호를 입력하거나 지도에서 실제 점을 선택하세요. 시작·끝은 같은 구간에서 선택하고, 각 점 이동은 위의 점 이동 도구를 사용하세요.

길 따라는 아래 걷기·등산·자전거 기준입니다. 확인 후 선택한 양 끝점 2개만 길담 서버로 보냅니다. 원본 GPX는 전송하지 않습니다. 양 끝점 간격은 30km 이내로 선택하세요. 길에 맞춘 대체 경로는 별도 구간으로 저장하여 원본과의 틈을 임의 직선으로 잇지 않습니다.

수정·추가한 점은 원래 시각·고도·확장값을 복사하지 않습니다. 고도 그래프는 선택 구간만 표시합니다. 수정본을 저장한 후 목록에서 다시 열 수 있습니다.

지도를 눌러 지점을 추가하고, 점을 끌어 옮기세요. 길 따라 자동 연결 지점 간격은 30km 이내로 찍으세요. 지점을 오른쪽 클릭하면 삭제합니다.

길 따라 모드에서는 찍은 경유점만 길담 서버로 보내 계산합니다. GPX 파일은 브라우저에서만 읽습니다. 지도에 없는 길·통제·위험구간은 반영되지 않을 수 있습니다.

⛰ 고도는 지형 고도 데이터(DEM)에서 읽어요. 30m 해상도라 실제와 조금 다를 수 있어요.
