여기에 GPX 파일을 놓으세요

무엇을 할까요?

기록한 길을 고치거나 새 코스를 그려 GPX 파일로 받습니다. 파일은 이 브라우저 안에서만 열려요.

고칠 곳을 확대한 뒤 점을 끌어서 옮기세요. 선을 누르면 점이 추가되고, 점을 고른 뒤 삭제로 지웁니다.

사용법 · 단축키
  • 점 클릭 선택 · 끌기 이동 · 선 클릭 점 추가 · Shift+클릭 구간 선택 · 우클릭 메뉴
  • ← → 이전/다음 점 · PgUp PgDn 10점씩 · Home End 구간 처음/끝
  • Shift+←/→ 구간 늘이기 · Delete 삭제 · + 뒤에 점 추가 · F 선택 점 확대
  • Ctrl+Z 되돌리기 · Ctrl+Shift+Z 다시 실행 · Enter 미리보기 적용 · Esc 취소/선택 해제
  • 휴대폰: 점을 눌러 고른 뒤 끌어 옮기세요. 고른 점 옆 +를 누르면 점이 추가됩니다. 구간은 구간 버튼을 누른 뒤 다른 끝 점을 누르세요.
  • 지도 색: 회색 점선은 원본, 빨강은 수정본, 청록은 선택 구간, 주황은 적용 전 미리보기입니다. 속이 채워진 점은 수정한 점입니다.
  • 옮기거나 추가한 점에는 원래의 시각·고도가 남지 않습니다. 원본 파일은 바뀌지 않습니다.
상세 편집 · 내보내기 옵션

길 따라 다시 그리기는 양 끝점 2개만 경로 서버로 보냅니다(30km 이내). 대체 경로는 별도 구간으로 저장해 원본과의 틈을 임의 직선으로 잇지 않습니다.

지도를 눌러 지점을 찍으세요. 점은 끌어서 옮기고, 선을 누르면 사이에 지점이 추가됩니다.

1 위치 맞추기기준점 없음

이미지와 바탕 지도의 같은 지점을 2곳 이상 짝지으면 크기·회전까지 자동으로 맞춥니다. 가운데 ✥를 끌면 이동, 모서리 ◢를 끌면 크기·회전입니다.

2 선 색 고르기
3 출발·도착

값이 클수록 선을 벗어난 지름길을 피합니다. 화살표 아이콘·글자로 선이 끊긴 곳은 짧게 건너뜁니다.

4 추출 · 보정

이미지 해상도 때문에 선이 실제 길과 수십 m 어긋날 수 있습니다. 보정은 추출한 선 위의 경유점만 길담 경로 서버로 보내 실제 길로 다시 잇습니다.

기록 비교

파일과 개인정보는 어떻게 다루나요?
  • GPX 파일과 지도 이미지는 이 브라우저 안에서만 읽고 서버로 올리지 않습니다.
  • 길 따라 잇기를 쓰면 찍은 지점(또는 옮긴 점과 앞뒤 기준점)의 좌표만 길담 경로 서버로 보냅니다.
  • 저장한 코스는 이 브라우저에만 보관됩니다. 브라우저 데이터를 지우거나 기기를 바꾸면 사라지니, 남길 코스는 GPX로 내려받으세요.
  • 고도는 30m 해상도 지형 자료에서 읽어 실제와 조금 다를 수 있습니다. 지도에 없는 길·통제 구간은 반영되지 않을 수 있습니다.
